1. Project: Water-Airtag (Sudan Hackathon)For this, you are using the Vehicle Routing Problem (VRP) solver. The constraints ensure your water trucks don't act like magic teleporters with infinite water.Capacity Constraint (The "Barrel" Limit):What it does: Ensures a truck never delivers more water than it can carry.In Code: Each location has a Demand (e.g., 200L). As the truck moves, the solver adds these up. If the sum exceeds the vehicle_capacity (e.g., 2000L), the solver forces the truck to return to the depot.Distance/Fuel Constraint (The "Scarcity" Limit):What it does: In Sudan, fuel is expensive. You set a constraint on the Maximum Distance any single vehicle can travel to ensure no driver gets stranded.Depot Constraint (The "Home Base"):What it does: All routes must start and end at the same location (the water station). This prevents the "optimal" route from being a one-way trip to nowhere.Integer Scaling (The "Math" Limit):What it does: OR-Tools works best with integers. Since your GPS coordinates and pressure readings are FLOAT8 (decimals), you must scale them up (e.g., multiply by 10,000) before feeding them to the solver, then scale the answer back down.2.
